BARDO STUDIO · GUÍA DE INSTALACIÓN Y USO (WINDOWS)
═════════════════════════════════════════════════

REQUISITOS
  · Windows 10 o 11, 64 bits.
  · Unos 500 MB de espacio libre en disco.
  · No necesitas Node, Bun ni Python: todo va incluido.

INSTALACIÓN
  1. Ejecuta BardoStudio-Setup-1.0.3.exe.
  2. Si aparece "Windows protegió tu equipo" (SmartScreen, porque el
     instalador no está firmado): "Más información" → "Ejecutar de todas
     formas".
  3. Sigue el asistente (instalación por usuario: no pide permisos de
     administrador; puedes cambiar la carpeta de destino).
  4. Al abrir «Bardo Studio» verás unos segundos de preparación: el primer
     arranque copia los recursos a tu carpeta de datos. Los arranques
     siguientes son inmediatos.

PRIMEROS PASOS EN LA APP
  1. Fase 1: pulsa «Demo con voz real (recomendada)» para probar el flujo
     completo sin grabar nada.
  2. Para tus propios audiolibros: arrastra o selecciona tu WAV/MP3 de
     narración (mejor de 3 horas o menos por proyecto).

LA IA DE LA FASE 2 ES REEMPLAZABLE (elige una opción)
  La Fase 2 (transcripción + curva de tensión) necesita un servicio de IA.
  La app NO depende de uno solo: elige el que quieras en «Ajustes de IA»
  (engranaje, arriba a la derecha). Todo lo demás (silencios, música,
  efectos, mezcla, editor, exportación, informes) funciona 100 % en tu
  equipo sin IA.

  OPCIÓN A · TU PROPIA API (recomendada: la app habla DIRECTAMENTE con el
  servicio que TÚ elijas, sin depender de nadie más)
    1. Consigue una clave de API de OpenAI, Groq (con capa gratuita),
       Mistral u otro servicio compatible con el formato de OpenAI. También
       sirve un servidor local (whisper.cpp, LM Studio, vLLM…): sin coste.
    2. En la app: engranaje «Ajustes IA» → pestaña «API propia» →
       elige el servicio (se rellenan URL y modelos) → pega tu clave →
       «Guardar y probar». La app hace una prueba REAL antes de guardar.
    · Puedes poner solo el modelo de transcripción, solo el de chat
      (tensión) o ambos. Sin modelo de chat, la tensión se calcula con la
      heurística local.

    COMBINACIÓN 100 % LOCAL CON LM STUDIO + WHISPER (sin coste, sin
    salir a internet) — nueva en 1.0.3:
    · LM Studio NO transcribe (aún no tiene el endpoint de transcripción),
      PERO sí hace el análisis de tensión (chat). Whisper.cpp hace la
      transcripción. La app 1.0.3 permite usar DOS URLs: una para chat y
      otra para transcripción.
    · Pasos:
      1) LM Studio: pestaña «Developer» → activa el servidor local
         (puerto 1234) y carga un modelo de chat (p. ej. llama-3.1-8b o
         qwen2.5-7b). En «API Keys» puedes dejar cualquier clave o crear
         una; la que pongas la escribes también en Bardo (mínimo 8
         caracteres; si LM Studio no pide clave, escribe p. ej.
         «lm-studio-local»).
      2) Whisper.cpp: descarga whisper.cpp y un modelo GGUF (p. ej.
         whisper-large-v3-turbo o ggml-base.bin) y lanza su servidor:
         whisper-server -m ggml-base.bin --port 8080
         (sirve /v1/audio/transcriptions, el formato de OpenAI).
      3) En Bardo: «API propia» → URL base http://localhost:1234/v1 →
         «URL de transcripción aparte» http://localhost:8080/v1 →
         modelo de chat: el nombre exacto que muestra LM Studio →
         modelo de transcripción: ggml-base.bin (o el que cargues) →
         clave → «Guardar y probar».
    · Solo whisper.cpp (sin LM Studio): pon http://localhost:8080/v1 en
      la URL base y deja la de transcripción vacía; la tensión usará la
      heurística local.

  OPCIÓN B · DEEPGRAM (solo transcripción)
    1. Clave en deepgram.com → API Keys.
    2. Pestaña «Deepgram» → pega la clave → «Guardar y probar»
       (transcribe con nova-2 en español; la tensión usa la heurística).

  OPCIÓN C · Z.AI INCLUIDA (vía la web de Bardo Studio)
    1. Abre Bardo Studio en el navegador (la dirección de siempre, la de
       donde descargaste el instalador) y entra en «Ajustes IA»: verás la
       URL con un botón «Copiar».
    2. En la app de escritorio, pestaña «Incluida» → pega esa URL →
       «Conectar»: la app la prueba de verdad y, si responde, queda
       guardada.
    · Nota honesta: esta opción necesita que la web sea accesible
      mientras la uses. Las opciones A y B no dependen de la web.

  DÓNDE SE GUARDAN TUS CLAVES
  · %APPDATA%\Bardo Studio\app\.bardo-ia.json (opciones A y B; se
    conserva al actualizar; solo lo lee el servidor local de la app).
  · %APPDATA%\Bardo Studio\app\.z-ai-config (opción C / credenciales
    manuales avanzadas).

  AVISOS HONESTOS
  · Con las opciones A/B tu clave viaja ÚNICAMENTE de tu equipo al
    servicio de IA que hayas elegido (https de su API).
  · Si el análisis de tensión no llega al LLM, la app continúa con su
    heurística local (se marca como «heurístico»).

  OPCIONES AVANZADAS
  · Credenciales Z.AI propias: crea %APPDATA%\Bardo Studio\app\.z-ai-config
    con {"baseUrl": "https://TU-ENDPOINT", "apiKey": "TU-CLAVE"} y
    reinicia la app (el archivo manual tiene prioridad y la app nunca lo
    sobrescribe).
  · Variables de entorno generales en %APPDATA%\Bardo Studio\bardo.env
    (líneas CLAVE=VALOR), inyectadas en el servidor interno.

INFORME PDF
  Incluye un Python embebido con ReportLab: la Fase 6 genera el PDF sin
  que instales nada. Si algún antivirus bloquea ese python.exe interno,
  puedes instalar Python 3.12+ con «pip install reportlab» y Bardo lo
  usará automáticamente.

DÓNDE VIVEN TUS DATOS
  %APPDATA%\Bardo Studio\
  ├── app\                     ← la aplicación en ejecución (no tocar)
  │   ├── db\user-music\       ← tu música importada
  │   ├── db\user-sfx\         ← tus efectos importados
  │   ├── db\proyectos\        ← tus proyectos guardados
  │   ├── .bardo-ia.json       ← tus proveedores de IA y claves
  │   └── .z-ai-config         ← relé de la web / credenciales manuales
  ├── bardo-servidor.log       ← registro técnico de soporte
  └── version-instalada.txt

  Copia de seguridad de TODO tu trabajo: copia la carpeta
  %APPDATA%\Bardo Studio\app\db (y .bardo-ia.json si no quieres volver
  a pegar las claves).

ACTUALIZAR / DESINSTALAR
  · Actualizar: ejecuta el instalador de la nueva versión; tus datos
    (música, efectos, proyectos y claves de IA) se conservan.
  · Desinstalar: Configuración → Aplicaciones → Bardo Studio. Los datos
    quedan en %APPDATA%\Bardo Studio (bórralos a mano si quieres).

PROBLEMAS
  · «La IA de transcripción no está conectada»: abre «Ajustes IA» y
    elige un proveedor (sección anterior).
  · «La prueba falló»: revisa la URL, la clave y los modelos del
    proveedor; los mensajes indican el código de error del servicio.
  · La ventana no abre / error del servidor: mira bardo-servidor.log.
  · Audio entrecortado en el editor: cierra otras apps con audio.
  · El antivirus enumera el instalador: es el aviso normal de binarios
    sin firma; verifica el hash SHA256 con el editor antes de ejecutar.
